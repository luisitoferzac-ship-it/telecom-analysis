# telecom-analysis
Análisis de clientes en empresa de telecomunicaciones
El objetivo del proyecto se basa en segmentar por edades y nivel de uso de clientes para optimizar la oferta comercial de acuerdo a las necesidades de cada grupo.
Los datasets utilizados fueron 3: plans, users_latam y usage.
Las etapas del análisis realizadas fueron: detectar sentinels y fechas fuera de rango, reemplazar estos datos haciendo una limpieza básica, revisar las medidas y comportamientos de usuarios, creacion de histogramas y segmentación de clientes.
